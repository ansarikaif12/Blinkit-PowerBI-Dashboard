# Blinkit Sales & Outlet Performance Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze Blinkit's sales, outlet performance, item categories, outlet sizes, and customer ratings.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Total Sales | $1.20M |
| No. of Items | 8,523 |
| Average Sales | $141 |
| Average Rating | 3.92 |

## 📈 Analysis

The dashboard provides insights into:

- Sales by outlet establishment year
- Sales by outlet location
- Sales by outlet size
- Sales by fat content
- Sales by item type
- Outlet performance
- Item visibility
- Average ratings
